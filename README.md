Website scrollytelling sinematik interaktif tentang kelestarian hutan tropis Indonesia — mengajak pengunjung menyusuri keindahan hutan nusantara, krisis kebakaran hutan dan lahan (karhutla), dampak kesehatan bagi masyarakat, hingga pesan pemulihan dan reboisasi.

---

## Deskripsi Website

**THE FOREST** adalah pengalaman web visual berbasis scroll (*scroll-driven storytelling*) yang terdiri dari 8 scene utama:

1. **The Gateway** — Pembuka sinematik dan pengenalan pesan utama serta bagian *About*.
2. **The Canopy (Wonderful of Indonesia)** — Mengangkat kekayaan kawasan hutan Indonesia (`124.975.956` hektare, flora & fauna) disertai galeri foto interaktif.
3. **The Inferno (Forest and Land Fires / Burning The Future)** — Visualisasi kebakaran hutan dengan galeri foto 3D Cover Flow yang dapat digeser dan diperbesar.
4. **Statistic** — Dasbor statistik dampak karhutla (luas lahan terbakar, korban langsung, dan kasus gangguan pernapasan/ISPA) lengkap dengan modal detail.
5. **The Ashes (What Remains)** — Atmosfer pasca-kebakaran sebagai refleksi kerusakan hutan.
6. **The Human Toll (Health Impacts)** — Daftar interaktif dampak kabut asap terhadap kesehatan manusia.
7. **The Rebirth (Reforest)** — Pesan harapan untuk penanaman kembali dan pemulihan hutan.
8. **The Contact (Let's Build)** — Penutup kolaboratif beserta tautan kontak.

Website ini juga dilengkapi dengan loading screen awal, navigasi **Liquid Morphing Transition**, efek 3D pengikut kursor pada kartu dan teks, backsound dinamis antar-scene dengan tombol toggle `SOUND ON/OFF`, serta tampilan responsif untuk desktop dan mobile.

## Petunjuk Instalasi dan Cara Menjalankan Project

### Prasyarat
- **Node.js** versi 18 atau lebih baru (disarankan LTS v20+)
- **npm** (terpasang bersama Node.js)

### Langkah Instalasi & Menjalankan (Development)

1. **Buka Code Editor** (kemudian clone repository):
   ```bash
   git clone https://github.com/sundaay03/webdesign_Zayyan-Cihuy_technoversary_vol.II
   ```

2. **Masuk ke direktori project**:
   ```bash
   cd webdesign_Zayyan-Cihuy_technoversary_vol.II
   ```

3. **Instal seluruh dependensi**:
   ```bash
   npm install
   ```

4. **Jalankan server development**:
   ```bash
   npm run dev
   ```

5. **Buka di browser**:
   Akses [http://localhost:3000](http://localhost:3000).
